# DAA--BITONIC-SORTING-ALGORITHM
Bitonic Sort – DAA Poster Presentation

This repository contains a poster presentation on the Bitonic Sort algorithm, created as part of the Design and Analysis of Algorithms (DAA) coursework.

The poster explains the concept of bitonic sequences, the working mechanism of the algorithm, pseudocode implementation, and the time complexity proof using the Master Theorem. It also highlights the role of Bitonic Sort in parallel computing and sorting networks.

Overview

Bitonic Sort is a parallel sorting algorithm that operates by first creating a bitonic sequence (a sequence that increases and then decreases) and then applying a bitonic merge process to produce a fully sorted sequence.

Unlike many traditional sorting algorithms designed for sequential processors, Bitonic Sort is particularly suitable for parallel architectures, making it useful in hardware sorting networks and GPU-based systems.
